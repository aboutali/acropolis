# Module 02 — src/02-helpers.js  (the shared geometry library)
Signature: `window.makeHelpers = function (THREE, mats) { var H = {}; ...; return H; };`
Implement EVERY helper in the preamble table with exactly those names and signatures. Read `window.CFG.SEG` for segment counts (fallback to {colRadial:40, colHeight:4, capital:24} if CFG is missing). Notes per helper:

- `H.noise2(x, z, seed)`: deterministic value noise in [-1,1]. Hash lattice points: `function hash(ix, iz){ var s = Math.sin(ix*127.1 + iz*311.7 + seed*74.7) * 43758.5453; return s - Math.floor(s); }`, bilinear-interpolate with smoothstep, sum 2 octaves (weights 0.65/0.35), map to [-1,1], clamp.
- `H.instance(geo, mat, transforms)`: `new THREE.InstancedMesh(geo, mat, transforms.length)`; for each transform compose a `THREE.Matrix4` from position, `new THREE.Quaternion().setFromEuler(new THREE.Euler(rx, ry, rz))`, scale; defaults r=[0,0,0], s=[1,1,1]; `setMatrixAt`; `instanceMatrix.needsUpdate = true`; castShadow = receiveShadow = true.
- `H.makeDoricColumns(positions, opts)`: defaults {height:10.4, baseD:1.9, topD:1.48, flutes:20, entasis:0.02, y:0}. Shaft: `new THREE.CylinderGeometry(topD/2, baseD/2, height*0.92, Math.min(40, flutes*2), SEG.colHeight)`. Modulate vertices: for each vertex (x,y,z): theta = atan2(z, x), r = sqrt(x²+z²), yN = (y + shaftH/2)/shaftH, newR = r * (1 - 0.035*(0.5 + 0.5*cos(flutes*theta))) * (1 + entasis*sin(PI*yN)); write back x = newR*cos(theta), z = newR*sin(theta); `computeVertexNormals()`. Echinus: `CylinderGeometry(topD*0.55, topD*0.5, 0.35, SEG.capital)`. Abacus: `BoxGeometry(topD*1.35, 0.3, topD*1.35)`. Three InstancedMeshes via H.instance with transforms placing the shaft centre at y + shaftH/2, echinus centre at y + shaftH + 0.175, abacus centre at y + shaftH + 0.35 + 0.15. Material `mats.marbleWorn`. Return a Group holding the 3.
- `H.makeIonicColumns(positions, opts)`: defaults {height:6.5, baseD:0.85, topD:0.72, flutes:24, y:0}. Base: `CylinderGeometry(baseD*0.62, baseD*0.68, 0.3, 24)`; shaft like Doric (shallower flutes 0.025, no entasis, height*0.86) sitting on the base; capital: two `TorusGeometry(topD*0.22, topD*0.09, 6, 12)` volutes per column, rotated PI/2 about x, placed at x = ±topD*0.55 at the shaft top; plus a `BoxGeometry(topD*1.5, 0.22, topD*1.1)` abacus above. Use H.instance for base, shaft, abacus, and ONE InstancedMesh for all volutes. Material `mats.marbleWorn`.
- `H.makeSteppedBase(w, d, steps, stepH, inset)`: inset default 0.7. For i in 0..steps-1: `BoxGeometry(w + 2*inset*i, stepH, d + 2*inset*i)` centred at y = -stepH*(i + 0.5). `mats.marble`. Top face is at y=0.
- `H.makeEntablature(w, d, h, o)`: o defaults {triglyphs:true, triglyphCount:8, cornice:true, guttae:false}. Architrave: ring of 4 boxes (thickness 1.4) of height h*0.40 at the bottom, `mats.marble`. Frieze ring of height h*0.35 above it in `mats.marbleShadowed`. Triglyphs: one InstancedMesh of `BoxGeometry(0.85, h*0.35, 0.12)` in `mats.marble` set proud of each face by 0.12; `triglyphCount` on each x-face (short) and `Math.round(triglyphCount*d/w)` on each z-face (long), evenly spaced, rotated PI/2 about y on the z-faces. Cornice: ring of height h*0.25 overhanging 0.45 on all sides at the top, `mats.marble`. Group bottom at y=0.
- `H.makePediment(w, d, h, o)`: o defaults {figures:9, relief:true}. Tympanum: `THREE.Shape` triangle (-w/2,0),(w/2,0),(0,h) → `new THREE.ExtrudeGeometry(shape, {depth:d, bevelEnabled:false})` translated -d/2 in z, `mats.marbleShadowed`. Raking cornice: two boxes of length sqrt((w/2)²+h²)+0.4 × 0.4 × (d+0.6) in `mats.marble`, rotated ±atan2(h, w/2) about z, centred on each slope. Figures: `o.figures` × `H.makeFigure(hf)` at x evenly spread in [-w*0.42, w*0.42], hf = max(0.6, 0.85*h*(1 - abs(x)/(w/2))), z = d/2 + 0.2. Bottom at y=0.
- `H.makeGableRoof(w, d, pitch, o)`: o defaults {tiles:true, acroteria:false}. Ridge runs along z (length d) at height ridgeH = (w/2)*pitch. slopeLen = sqrt((w/2)² + ridgeH²). Two `BoxGeometry(slopeLen, 0.25, d)` slabs in `mats.terracotta`, rotated ∓atan(pitch) about z, centred at x = ±w/4, y = ridgeH/2. If tiles: one InstancedMesh of `BoxGeometry(0.6, 0.06, 0.7)` in `mats.terracotta`, rows every 0.75 along the slope and 0.65 along z on both slopes, 0.14 above the slab surface, same rotation; cap count at 1200 (increase spacing proportionally if over). Ridge cap: `BoxGeometry(0.5, 0.3, d)` at y = ridgeH. If acroteria: 3 `ConeGeometry(0.4, 1.2, 8)` per gable end (apex and both corners) in `mats.marble`.
- `H.makeFigure(height)`: default 1.8; Group origin at the feet, all `mats.marble`: two leg cylinders (r 0.07h, len 0.45h) at x = ±0.06h; torso `CylinderGeometry(0.11h, 0.13h, 0.35h, 10)` centred at 0.625h; two arm cylinders (r 0.04h, len 0.3h) at x = ±0.16h tilted ±0.25 rad about z, centred at 0.62h; neck cylinder r 0.03h len 0.06h; head `SphereGeometry(0.08h, 12, 8)` at 0.9h.
- `H.makeCaryatid(height)`: default 2.3. Plinth `CylinderGeometry(0.35, 0.38, 0.25, 16)`; body `CylinderGeometry(0.28, 0.42, height*0.72, 16)` with vertices modulated r *= 1 + 0.06*cos(8*theta) (peplos folds) in `mats.marble`; two arm cylinders r 0.07 close to the body; head `SphereGeometry(0.14, 12, 8)`; capital drum `CylinderGeometry(0.32, 0.30, 0.28, 16)` above the head. Origin at the feet; total ≈ height.
- `H.makeWall(points, height, thickness, mat)`: mat default `mats.rockDark`. For each consecutive pair: `BoxGeometry(len + thickness, height, thickness)` at the midpoint, rotated about y by `-Math.atan2(dz, dx)`, centre y = height/2. Reuse one unit box scaled per segment is fine.
- `H.makeRockOutcrop(w, d, h, seed)`: `new THREE.PlaneGeometry(w, d, 48, 24)`; `geo.rotateX(-Math.PI/2)`; for each vertex set y = h * (0.6*H.noise2(x*0.02, z*0.02, seed) + 0.4*H.noise2(x*0.08, z*0.08, seed + 9)); `computeVertexNormals()`; `new THREE.Mesh(geo, mats.rock)` with receiveShadow true, castShadow false.
- `H.makeCella(w, d, h, o)`: o defaults {doorWidth:4, doorSide:'+z'}. Thickness 1.2, `mats.marbleWorn`. Four wall boxes; the `doorSide` wall ('+z','-z','+x','-x') is split into two flanking boxes plus a lintel box above the door (door height h*0.7). Bottom at y=0.
- `H.makeBlockCourse(w, d, h, blockLen)`: ring of `BoxGeometry(blockLen*0.96, h*0.96, 1.0)` blocks along the 4 sides of a w×d rectangle, one InstancedMesh, `mats.marbleWorn`, bottom at y=0.

Keep it under ~280 lines. Create each geometry once per call and share between instances. Never create materials.
